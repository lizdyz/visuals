# Logo Images

Please place your logo images in this directory with the following names:

1. **logo-white-bg.png** - The colorful brain logo with white background (for light mode)
2. **logo-black-bg.png** - The colorful brain logo with black background (for dark mode)
3. **sweetbot-logo.png** - The SweetBot logo (blue and purple bot icon with "Bot" text)

## Image Specifications

- Format: PNG with transparent background preferred
- Recommended size: 400x400px or higher
- Optimize for web to reduce file size

The aviation dashboard will automatically use these images when they are present, with appropriate fallbacks if they're not found.
