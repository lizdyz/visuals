## 🎯 Key Concepts

**SweetBOS Platform** is a transformation platform for financial advisors, structured as:
- **Missions** - Bundle of journeys representing major business goals
- **Journeys** - 12 core business areas (e.g., Client Acquisition, Operations)
- **Components** - 78 scoreable business capabilities (6-10 per Journey)
- **Quests** - Structured projects that advance Components through maturity levels
- **Sparks** - 3-10 minute atomic actions that make up Quests

**Maturity Model** - All Components progress through 5 levels:
- **L1 (Lacking)** - No system, unaware
- **L2 (Learning)** - Researching, understanding
- **L3 (Launching)** - Basic system in place
- **L4 (Leveraging)** - Systematized, optimizing
- **L5 (Leading)** - Mastery, teaching others
