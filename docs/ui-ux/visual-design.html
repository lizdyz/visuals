SweetBOS Visual Experience Design System

The Interface Layer | Generated: November 9, 2025

Purpose: This document defines HOW users SEE and INTERACT with every level of the system - from Mission to Spark. It provides multiple view options and toggle states so users can experience their progress in the way that works best for them.

Core Principle: The experience IS the product. Every visual element must reduce cognitive load, provide focused context, and make advancement feel natural and rewarding.

5. Spark Presentation Types (The Execution Layer)

Sparks adapt their visual presentation based on the type of cognitive work required. Here are the 6 core Spark types and their optimal UI patterns:

Type 1: QUESTION Spark

Purpose: Gather information from user's knowledge

UI Pattern: Form with input fields, optional help text

Co-Evolution Mode: Explore → open-ended, Attune → multiple choice, Integrate → structured fields

┌─────────────────────────────────────────────────────────────────┐ │ Spark: "List your 10 most common client questions" │ │ │ │ [Text area - expandable] │ │ 1. ________________________________________________ │ │ 2. ________________________________________________ │ │ 3. ________________________________________________ │ │ ... │ │ │ │ 💡 Tip: Think about the questions you answer repeatedly │ │ │ │ [+ Add More] [Save Draft] [Complete] │ └─────────────────────────────────────────────────────────────┘

Purpose: Build something tangible (template, document, system)

UI Pattern: Rich text editor OR structured template with AI assist

Co-Evolution Mode: Explore → freeform, Attune → template selection, Integrate → guided creation

8. Co-Evolution Framework: How UI Changes by Mode

EXPLORE Mode

  • Layout: Expansive, spacious
  • Options: 5-15+ visible at once
  • Navigation: Free, non-linear
  • Language: "What's possible..."
  • Pressure: None - safe to wander
  • Spark Types: Question, Reflection

ATTUNE Mode

  • Layout: Comparison views
  • Options: 2-3 focused choices
  • Navigation: Guided comparison
  • Language: "Which resonates..."
  • Pressure: Low - test fit
  • Spark Types: Decision, Definition

INTEGRATE Mode

  • Layout: Focused, minimal
